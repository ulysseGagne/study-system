# The tutor

How the student studies a course with Claude, from the raw slides to the exam: one file per job, pointed at one course folder at a time. It never names a course, except as an example.

## What is here

1. [[welcome]]: the guided start, then each part of the system the first time it's needed.
2. [[starting-a-session]]: which course, where it stands, what's waiting, which activity.
3. [[course-folder-format]]: what a course folder holds and how its files are written; the contract between the tutor and a course.
4. `studying/`: the activities: teaching a chapter, practising, preparing for an exam, working through an assignment.
5. `preparing-material/`: turning raw material into a course folder: setting it up, transcribing files, lecture recordings.
6. [[improving-the-system]]: how the tutor changes with the student's feedback, and where each rule goes.
7. [[why-it-works]]: the idea behind it.
8. `tools/`: the status, the slide viewer and its server, the transcription and the slide alignment, the exam sheet's print layout.

## How it fits together

1. **The tutor**, this folder: the method and the tools.
2. **A course's data**, `courses/<course>/`, on this Mac only: the material and where the student stands, in the format of [[course-folder-format]].
3. **How the student learns**: [[how-i-learn]], for any course.

## Where it comes from

Ulysse Gagné's study system, built course after course since October 2025, each rule born from a real study session ([[why-it-works]]). This copy dates from November 10, 2026; from here on, it changes with its new student.

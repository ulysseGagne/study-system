# Studying

The activities the tutor runs with the student, one file each; [[starting-a-session]] says which one a session picks.

1. [[teaching-a-chapter]]: the first pass, slide by slide, each official question asked as soon as it can be answered.
2. [[practising-exercises]]: the official questions with a rappel before each, Socratic feedback, the hard ones drilled again.
3. [[preparing-for-an-exam]]: the plan, the review, the sheet, and the quick review of exam day.
4. [[working-through-an-assignment]]: a graded assignment, re-taught, guided to the exact answer, then the key.
